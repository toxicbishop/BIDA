# Business Intelligence and Data Analytics (BIDA)

A comprehensive collection of laboratory experiments, assignments, and mini-projects developed as part of the **Business Intelligence and Data Analytics (BCB701)** course.

This repository demonstrates fundamental and advanced concepts in Business Intelligence, Data Analytics, Data Mining, Machine Learning, Data Visualization, and Text Analytics using Python and industry-standard BI tools.

---

## Course Overview

Business Intelligence and Data Analytics focuses on extracting meaningful insights from data to support informed decision-making. The course covers descriptive, predictive, and prescriptive analytics through practical implementations involving data preprocessing, visualization, machine learning, and web analytics.

## Installation

Clone the repository:

```bash
git clone https://github.com/toxicbishop/Business-Intelligence-and-Data-Analytics-BIDA.git
```

Move into the project directory:

```bash
cd Business-Intelligence-and-Data-Analytics-BIDA
```

Create a virtual environment:

### Windows PowerShell

```bash
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```
### Windows Bash
```bash
python -m venv .venv
.venv\Scripts\activate
```
### Linux/macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```
